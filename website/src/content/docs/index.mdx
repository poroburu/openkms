openKMS is a small, deny-by-default signing service for operators who want
hardware-backed keys without handing raw private material to trading agents or
automation.

<CardGrid>
  <Card title="HSM-only signing">
    Signing keys live in a YubiHSM2. The service signs through the HSM and never
    emits private key material.
  </Card>
  <Card title="Policy before signature">
    Per-key rate limits, spend caps, allowlists, and a kill switch guard every
    signing request.
  </Card>
  <Card title="Operator friendly">
    Systemd units, remote smoke tests, testnet broadcast checks, and Prometheus
    metrics are documented together.
  </Card>
  <Card title="Checked API docs">
    The HTTP API reference points at a generated OpenAPI spec that is checked in
    CI for drift.
  </Card>
</CardGrid>
