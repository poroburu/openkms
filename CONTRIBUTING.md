# Contributing

Org hub: [`../openkms-whitepaper`](../openkms-whitepaper/). Git policy: [`../openkms-whitepaper/coordination/git-workflow.md`](../openkms-whitepaper/coordination/git-workflow.md). Parent umbrella: [`openKMSio/okms`](https://github.com/openKMSio/okms).

- Until a Linear workspace is attached, open work lives in git (PRs and whitepaper process docs). When Linear exists, it owns open work and decisions; close when decided, not when a PR exists.
- Git = facts that would otherwise lie. One canonical file; pointers elsewhere.
- PRs preferred. Do not merge or push to `main`/`master` without explicit user approval.

After changing this repo, bump the parent pin ([docs/pin-bump.md](docs/pin-bump.md)).
